# 🦋 꿈틀나비 하루 — 설치 안내서

습관·일정 기록 앱입니다. 노트북과 휴대폰에서 같은 데이터를 함께 씁니다.

## 전체 구조를 그림으로 보면

| 역할 | 맡은 도구 | 비유 |
|---|---|---|
| 데이터 보관 | 구글 스프레드시트 | **공책** — 모든 기록이 여기 적힘 |
| 서버(API: 앱과 시트를 이어 주는 창구) | 앱스스크립트 `Code.gs` | **사서** — 앱의 요청을 받아 공책에 쓰고 읽어 줌 |
| 화면 | GitHub Pages `index.html` | **진열창** — 어느 기기에서든 주소로 열림 |

노트북·휴대폰은 각자 진열창(앱)을 열고, 같은 사서에게 같은 공책을 요청하니 자동으로 맞춰집니다.

파일: `index.html`(앱 화면), `Code.gs`(서버), `README.md`(이 안내서), 앱 아이콘 `icon.svg`·`icon-180.png`·`icon-192.png`·`icon-512.png`, `manifest.json`(휴대폰 홈 화면용 설정)

## 1단계. 구글 시트 + 앱스스크립트 (약 10분)

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `꿈틀나비 하루 DB` 로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 편집기에 있던 코드를 모두 지우고 `Code.gs` 내용을 붙여넣은 뒤 💾 저장합니다.
4. 위쪽 함수 목록에서 **`setup`** 을 고르고 **▶ 실행**합니다.
   - "승인 필요" 창 → 내 구글 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → (안전하지 않음)으로 이동 → 허용**. 내가 만든 스크립트라 괜찮습니다.
5. 아래 **실행 로그**에 `앱에 입력할 비밀키: xxxxxxxx` 가 보입니다. 이 값을 메모해 두세요. (잊어버리면 `showKey` 를 실행하면 다시 보여 줍니다.)
6. 오른쪽 위 **배포 → 새 배포**
   - 톱니바퀴 ⚙ → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둡니다.

> 💡 "모든 사용자"로 열어도 비밀키 없이는 읽기·쓰기가 막힙니다.

> ⚠️ 나중에 `Code.gs` 를 고치면 **배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포** 로 올려야 합니다. "새 배포"를 하면 주소가 바뀌어 앱 설정을 다시 해야 해요.

## 2단계. GitHub에 앱 올리기 (코딩 없이, 약 10분)

1. [github.com](https://github.com) 에 가입·로그인합니다.
2. 오른쪽 위 **＋ → New repository**
   - Repository name: `kkumteul-haru` (원하는 영문 이름)
   - **Public** 선택 (무료 계정의 GitHub Pages는 공개 저장소에서만 됩니다)
   - **Create repository**
3. 저장소 화면에서 **uploading an existing file** 링크(또는 **Add file → Upload files**)를 누르고 `index.html`, `README.md`, 아이콘 파일 4개, `manifest.json` 을 한꺼번에 끌어다 놓은 뒤 **Commit changes**.
   - `Code.gs` 는 올려도 되고 안 올려도 됩니다. 비밀키는 코드에 들어 있지 않아 공개돼도 안전합니다.
4. 저장소의 **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
5. 1~2분 뒤 같은 화면 위쪽에 `https://아이디.github.io/kkumteul-haru/` 주소가 생깁니다. 이게 앱 주소예요.

---

## 3단계. 각 기기에서 한 번씩 연결

1. 앱 주소를 열고 **🪴 가꾸기 → 서버(구글 시트) 연결** 에 웹 앱 URL과 비밀키를 넣고 **연결하기**.
2. 오른쪽 위 점이 초록색 **동기화됨** 이면 성공입니다.
3. 홈 화면에 앱처럼 추가하기
   - **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**
   - **안드로이드(크롬)**: ⋮ → **홈 화면에 추가**
   - **노트북(크롬)**: 주소창 오른쪽 설치 아이콘 또는 ⋮ → **저장 및 공유 → 바로가기 만들기**

> URL·비밀키는 **그 기기 브라우저에만** 저장됩니다. 노트북 1번, 휴대폰 1번만 입력하면 됩니다.

### 동기화는 이렇게 됩니다

- 체크하면 화면이 **바로 바뀌고**, 0.7초 뒤 시트에 저장됩니다.
- 인터넷이 끊겨도 기기에 보관했다가, 다시 연결되면 자동으로 올립니다.
- 앱을 다시 열거나 다른 앱에서 돌아올 때, 그리고 켜져 있는 동안 1분마다 최신 내용을 받아옵니다.
- 같은 항목을 두 기기에서 동시에 고치면 **나중에 저장한 쪽**이 남습니다.

## 4단계. Claude와 GitHub 연결하기 (앱을 고치고 싶을 때)

연결해 두면 "주간 화면에 ○○ 추가해 줘"라고 말했을 때 Claude가 **저장소 코드를 직접 고쳐서 GitHub에 올립니다.** 파일을 내려받아 다시 올릴 필요가 없어요.

**준비물**: Claude Pro 이상 요금제, GitHub 계정

1. [claude.ai/code](https://claude.ai/code) 에 접속합니다. (데스크톱 앱이나 휴대폰 Claude 앱의 **Code** 탭에서도 됩니다.)
2. **GitHub 연결** 안내가 나오면 누르고, GitHub 화면에서 **Authorize(승인)** 합니다.
3. **Claude GitHub 앱 설치**: 안내에 따라 [github.com/apps/claude](https://github.com/apps/claude/installations/new) 에서 **Install** → *Only select repositories* → `kkumteul-haru` 선택. (공개 저장소는 이 단계 없이도 읽을 수 있지만, 설치해 두면 편합니다.)
4. 입력창 아래 **저장소 선택**에서 `kkumteul-haru` 를 고르고 요청을 적습니다.
   - 예) `월간 화면에 '가장 많이 미룬 요일' 분석을 추가해 줘`
5. Claude는 작업용 **브랜치**(branch: 원본을 건드리지 않는 작업용 사본)에 변경을 올립니다.
   - 화면의 `+42 −18` 같은 표시를 눌러 바뀐 내용을 확인
   - **Create PR**(PR: 바꾼 내용을 원본에 합쳐 달라는 요청) → GitHub에서 **Merge pull request** 를 누르면 원본(main)에 합쳐집니다.
6. 1~2분 뒤 GitHub Pages가 자동으로 새 버전을 게시합니다. 휴대폰에서는 앱을 새로고침하세요.

> 💡 **안전 습관**: PR을 합치기 전에 Claude에게 "바뀐 부분을 쉬운 말로 요약해 줘"라고 하면 무엇이 달라졌는지 확인하기 좋습니다.

> 연결 없이 하는 방법: 일반 Claude 대화에서 수정된 `index.html` 을 받아 GitHub 저장소에서 파일 → ✏️ 연필 아이콘 → 전체 붙여넣기 → **Commit changes**.

## 5단계. 사전 · 영어로 말하기 설정

### 🔎 사전 (기본: 영어로)
- 우리말을 넣으면 **영어 단어**가, 영어를 넣으면 **영영 뜻풀이 + 우리말 뜻**이 나와요. 서버(시트) 연결만 되어 있으면 추가 설정 없이 동작해요.
- 국어사전 탭은 아래 '국어사전 뜻풀이' 설정을 하면 앱 안에서 바로 보여요.

### 💬 영어로 말하기 (우리말 → 자연스러운 영어)
- **기본**: 무료 Google 번역(앱스스크립트 내장)으로 바로 동작해요.
- **더 자연스럽게(선택)**: Claude를 연결하면 원어민이 실제로 쓰는 표현 + 상황별 대안 2개 + 뉘앙스 설명이 나와요.
  1. [console.anthropic.com](https://console.anthropic.com) 에서 API 키 발급(사용량만큼 요금, 문장 하나 번역에 1원도 안 되는 수준)
  2. 앱스스크립트 `setClaudeKey` 함수의 `'여기에_API_키'` 를 받은 키로 바꾸고 → `setClaudeKey` 선택 → ▶ 실행
  3. 첫 실행 때 '외부 서비스 연결' 권한을 허용
  - 결과 카드 오른쪽 아래에 `Claude` / `Google 번역` 중 무엇으로 번역했는지 표시돼요.
  - API 키는 시트에도 GitHub에도 남지 않고 앱스스크립트 안(스크립트 속성)에만 저장돼요.

### 국어사전 뜻풀이를 앱 안에서 바로 보기 (선택)

- **영어사전**은 따로 설정할 필요가 없어요. GitHub Pages 주소에서 열면 🔎 사전에 단어를 넣는 즉시 뜻·품사·예문이 앱 안에 나와요(무료 공개 사전 Free Dictionary API, 영영 풀이).
- **국어사전**은 표준국어대사전 오픈 API 인증키가 있어야 앱 안에 뜻풀이가 나와요. 키가 없어도 사전 버튼(표준국어대사전·우리말샘·네이버)은 바로 쓸 수 있어요.
  1. [표준국어대사전](https://stdict.korean.go.kr) 회원가입 → 로그인 → **오픈 API** 메뉴에서 인증키 신청
  2. 앱스스크립트 편집기에서 `setDictKey` 함수의 `'여기에_인증키'` 를 받은 키로 바꾸고 → 함수 목록에서 `setDictKey` 선택 → ▶ 실행
  3. 처음 실행하면 '외부 서비스 연결' 권한을 다시 물어요. 허용하면 끝. (코드를 고친 게 아니라 키만 저장한 것이라 다시 배포하지 않아도 돼요. 단, 이번 버전의 `Code.gs` 로 바꿔 붙여넣었다면 **배포 관리 → 새 버전**은 한 번 해 주세요.)

> 미리보기(Claude 화면)에서는 보안상 바깥 접속이 막혀 있어서, 앱 안 뜻풀이 대신 사전 바로가기 버튼만 동작해요.

## 자주 겪는 문제

| 증상 | 해결 |
|---|---|
| 점이 빨간색, "비밀키 확인 필요" | 비밀키 오타. 앱스스크립트에서 `showKey` 실행 후 다시 입력 |
| 점이 빨간색, "오프라인" | ① 웹 앱 URL이 `/exec` 로 끝나는지 ② 배포 시 액세스 권한이 **모든 사용자**인지 확인 |
| 코드를 고쳤는데 반영이 안 됨 | 앱스스크립트: **배포 관리 → 새 버전**으로 다시 배포 / 화면: 새로고침 |
| 시트에서 날짜가 이상하게 바뀜 | 시트 칸을 직접 고칠 때는 형식을 '일반 텍스트'로 두세요 |
| 데모 데이터가 보임 | 아직 서버에 연결 전입니다. 3단계를 진행하세요 |

## 시트 구조 (직접 볼 때 참고)

- `categories` 카테고리 · `routines` 반복 습관(days: 0=일 … 6=토) · `tasks` 하루짜리 할 일
- `logs` 날짜별 기록(id = 날짜|항목) · `events` 일정 · `links` 아티팩트 바로가기 · `memos` 메모(done = 한 일 표시)
